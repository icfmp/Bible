Installer Bible avec Logiciels GNOME

Installer une seule fois, puis utiliser flatpak update --user ou Logiciels. Le runtime GNOME provient de Flathub ; Bible utilise son propre canal de test signé.

Avant de remplacer une installation depuis un bundle, lire les instructions. Aucune suppression automatique de données.

Préversion susceptible de défauts. L’essai manuel sur le poste GNOME reste nécessaire.
