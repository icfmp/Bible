# Keyboard shortcuts

These shortcuts are documented for the current alpha:

| Shortcut | Action |
| --- | --- |
| `Ctrl+L` | Open Library |
| `Ctrl+T` | Open a new tab |
| `Ctrl+N` | Create a passage note |
| `Ctrl+Shift+N` | Open My notes |
| `F9` | Show or hide the study panel |
| `F11` | Toggle fullscreen reading |

Shortcut behavior may evolve as the interface is refined. Report any discrepancy in [GitHub Issues](https://github.com/icfmp/Bible/issues).
