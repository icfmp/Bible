# Appearance and accessibility

Bible is designed for comfortable reading, including longer sessions. You can customize the **reading area** without losing the familiar GNOME interface.

## Open reading appearance

Choose the **Aa** button (**Reading appearance**) in the main window to adjust how biblical text is displayed. Changes take effect immediately and are saved locally.

## Typography and layout

| Setting | Available options |
| --- | --- |
| **Reading font** | **Book** (serif) or **Simple** (sans-serif) |
| **Text size** | **12–64 pt**, using **A−** and **A+** |
| **Line spacing** | **Tight**, **Normal**, **Airy**, **Very airy** |
| **Text width** | **Narrow**, **Normal**, **Wide** |
| **Chapter numbers** | Show or hide chapter numbers |
| **Verse numbers** | Show or hide verse numbers |
| **Show highlights** | Show or hide saved verse highlights while reading |

Open **Layout** in the appearance menu to find line spacing and text width.

These options affect the reading experience; they do not change the biblical text itself. Appearance preferences are shared between reading tabs.

If you want to return to the defaults, select **Reset reading settings**.

## Reading colors and themes

Under **Reading mode**, choose:

- **System** — follow your desktop's light or dark appearance.
- **Day** — use the light appearance.
- **Night** — use the dark appearance.

You can also select a palette for each appearance:

| Day palettes | Night palettes |
| --- | --- |
| **White** — clear white background | **Dark grey** — softer dark background |
| **Paper (sepia)** — warmer, paper-like background | **Black** — black background |

Try different combinations of typography, spacing and palettes to find a comfortable balance.

### High-contrast mode

Bible recognizes the system's **high-contrast** setting and automatically uses dedicated high-contrast reading colors. While high contrast is enabled, the regular palette choices are unavailable, so the system accessibility setting takes priority.

## Immersive reading

Press **`F11`** or choose **Immersive mode** to enter a focused reading experience.

Immersive mode uses fullscreen and a dedicated reading layout to reduce distractions. It is **not simply the ordinary window-fullscreen command**. Use the same control to return to your usual reading workspace.

To reduce distractions without entering immersive mode, press **`F9`** to hide or show the study panel.

See [Reading and navigation](Reading-and-Navigation) for more ways to move through the text.

## Keyboard and language accessibility

Bible supports keyboard shortcuts for frequently used actions:

| Shortcut | Action |
| --- | --- |
| **`F9`** | Show or hide the study panel |
| **`F11`** | Enter or leave immersive reading |
| **`Ctrl+G`** | Choose a Bible passage |
| **`Ctrl+K`** | Enter a reference directly |
| **`Ctrl+L`** | Open the resource Library |

The interface is available in **English and French** and follows the application/system language configuration. Individual Bible texts and commentaries retain their own languages. Right-to-left biblical resources are displayed in their appropriate reading direction.

## Report an accessibility issue

Accessibility and visual consistency continue to improve during alpha development. If text is difficult to read, a control lacks a clear label, or keyboard navigation does not work as expected, please [open a GitHub issue](https://github.com/icfmp/Bible/issues). Include your Bible version, desktop environment and steps to reproduce the problem where possible.
