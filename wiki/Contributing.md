# Contributing and supporting Bible

Bible is free and open source. Contributions of all sizes are welcome.

- **Test the alpha:** install Bible, try normal reading and study tasks, and report problems.
- **Report bugs:** include reproducible steps and the installed build.
- **Suggest improvements:** explain the user problem and how a solution could preserve a simple interface.
- **Contribute code or translations:** read [AGENTS.md](https://github.com/icfmp/Bible/blob/main/AGENTS.md) and check existing issues first.
- **Support development:** [Patreon](https://www.patreon.com/BibleStudyApp) is available for optional financial support.

Please use English for public issues, pull requests and contributor documentation.
