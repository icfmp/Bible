# Source fidelity review: contextual study follow-ups

Related to #206, #218, #233, #235 and #238. This is an implementation audit, not client acceptance or a publication record.

- **Original text:** `StepData` imports the pinned STEP corpora/lexicon with their explicit token IDs, source spellings, reference convention and supplied lexical glosses. Word tiles use those gloss fields. The application does not translate English meanings, generate an alignment to translation words, or reconstruct absent tokens. Source-language descriptions and unsupported source mappings stay explicit. Verse excerpts use `local_excerpt` on the dialog-selected installed Reader and verified reference mapping; changing this selector does not navigate the main reading tab. Missing verses are unavailable, never copied from another edition. Bounded occurrence chips use actual corpus occurrences/counts, not sample counts.
- **Geography:** the existing OpenBible index retains ancient IDs, proposed modern IDs, coordinates, roles, uncertainty, evidence paths and bibliography. Map candidates are not silently deduplicated. Repeated proposals for the same modern ID can share a presentation heading while preserving each resolution. Conventional French place-name UI labels remain display aliases; source names are retained, and free-form source descriptions are no longer passed through that label translation table.
- **Historical context and photographs:** generated `study_data/place_context_v2.json` is an offline seed from the separately reviewed Bible-Resources preparation process. Its source identities, revisions, licenses and individual image credits remain intact. Unlike the old Jerusalem-only resource, new introductions are independently acquired source-language Wikipedia extracts, not application-authored French translations or summaries. Coordinate-source entities are explicitly qualified and never silently promoted to ancient-place identities. Unknown/mismatched identities and unsupported image licenses produce no invented substitute. See Bible-Resources `docs/PLACE_CONTEXT.md` for the actual bounded sample and omissions. Existing photograph cache files remain untouched.
- **Dictionary and people:** the common dialog exposes truthful unavailable states; no synthetic dictionary definitions, person relationships or data engines were introduced. These tabs await their separate data-backed work.
- **References and commentaries:** existing `reference_targets`, `reference_resolution`, `ReferenceData`, installed SWORD Readers and shared reference previews remain the source/navigation boundary. The visible-anchor correction changes follow behavior, not reference records or commentary text. Existing verified versification mapping is reused; absent mappings remain unavailable.
- **Notes:** editor rehosting uses the same rich editor, buffer, NoteStore and passage links. No schema migration, content rewrite or interpretation of personal notes was added. The context indicator uses transient reading marks and does not create saved highlights.
- **Module checking (#233 first deliverable):** installed .conf metadata and the official catalogue are read-only. A matching SWORD ID/version is never evidence of the same edition. The official committed catalogue has zero approved modules. Its GitHub Pages output is not configured (HTTP 404); the checker uses the verified raw.githubusercontent.com snapshot instead, without changing repository administration. No installer, atomic replacement or rollback is claimed; these require the separately testable second stage and real curated module provenance.

Validation evidence must distinguish developer GTK/X11 checks, the installed Flatpak runtime and client desktop acceptance. Keep #247 open: Escape in the language search field was reproducibly consumed without dismissing its popup and is now wired to the native popdown action. This is a measured dismissal defect, not proof of the complete reported session lock. Successful first-run/repeated-selector traces do not establish a cause for an intermittent failure that has not been reproduced.
