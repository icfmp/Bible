# Bible 0.1.0-alpha.2

Deuxième préversion Linux x86_64 pour les essais GNOME. L’alpha.1 reste disponible.

## Fonctions et corrections

Lecture de traductions téléchargées depuis CrossWire, recherche exacte hors connexion,
onglets indépendants, commentaires suivant le passage et notes Markdown locales.
Aucune traduction complète n’est embarquée. Interface française et anglaise.

- **#8** : progression réelle du téléchargement, activité quand la taille est inconnue,
  phase d’installation distincte et nouvelle tentative après erreur.
- **#9** : sélecteur avec recherche et liste des livres à gauche, grille des chapitres
  à droite ; sélection directe dans l’onglet actif, adaptation aux fenêtres étroites.
- **#10** : chevrons précédent/suivant sur les bords de la lecture, sans masquer le
  texte ; limites et chapitres réellement disponibles respectés.
- Icône bleue de Bible intégrée au paquet et au lanceur GNOME.

## Installation sous GNOME

Télécharger **Bible-0.1.0-alpha.2-linux-x86_64.flatpak** ci-dessous, puis l’ouvrir
avec **Logiciels** et choisir Installer/Mettre à jour. Flathub fournit le runtime
GNOME 49 ; une connexion est nécessaire pour son installation et le catalogue.
Ce fichier est un paquet local ; Bible n’est pas publiée sur Flathub.

Si une alpha est déjà installée et que Logiciels ne propose pas la mise à jour :

```sh
flatpak install --user --reinstall ./Bible-0.1.0-alpha.2-linux-x86_64.flatpak
flatpak run io.github.icfmp.Bible
```

Ne pas supprimer le profil : les ressources et notes locales y sont conservées.
`SHA256SUMS` donne les sommes des fichiers joints. Pour ne vérifier que le paquet :

```sh
sha256sum --ignore-missing -c SHA256SUMS
```

## Vérifications et limites

Le paquet joint provient du commit correctif dont la CI est réussie : tests Python,
interface GTK en français sous Xvfb, véritables entrées X11, téléchargement et
réouverture hors connexion de ressources CrossWire, construction puis installation
et import SWORD/interface dans le Flatpak. La provenance indique le commit exact,
le run de construction et la somme du paquet ; les sources correspondantes sont jointes.

**L’essai manuel de cette alpha sur notre poste GNOME reste à effectuer.**
Tester un téléchargement, les livres/chapitres, les flèches, le clavier, le thème
sombre et une fenêtre étroite. Les tests Xvfb ne remplacent pas cet essai.

Catalogue actuellement limité à CrossWire ; extension aux autres dépôts en #11.
Certains types de ressources, les textes verrouillés et certaines versifications
ne permettent pas toutes les fonctions. Comparaison de textes, audio et accès
YouVersion/Semeur hors connexion ne sont pas annoncés disponibles. Pas de paquet
Windows/macOS ni de synchronisation. Préversion susceptible de défauts.

Licence de Bible : GPL-2.0-only ; dépendances et textes téléchargés conservent
leurs licences propres, distinctes de celle de l’application.

## Signaler un problème

Ouvrir https://github.com/icfmp/Bible/issues avec la version **0.1.0-alpha.2**,
la distribution et version GNOME, les étapes, le résultat attendu/observé et,
si utile, une capture sans informations personnelles. Pour un défaut de lecture,
préciser la ressource et le passage. Pour les journaux, lancer
`flatpak run io.github.icfmp.Bible` dans un terminal et joindre les messages utiles
en retirant toute donnée privée.
