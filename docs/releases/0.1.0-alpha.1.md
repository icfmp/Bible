# Bible 0.1.0-alpha.1

Première préversion de Bible pour Linux x86_64, avec interface native GNOME
(GTK 4 et libadwaita), en français et en anglais. Cette version alpha est destinée
aux essais ; **l’essai manuel sur notre poste GNOME reste à effectuer**.

Bible est distribué sous GNU GPL version 2 uniquement (`GPL-2.0-only`).
Les dépendances et les textes téléchargés conservent leurs propres licences.

## Fonctions disponibles

- Téléchargement à la demande de Bibles et commentaires depuis CrossWire, avec
  langue, provenance et conditions affichées. Aucune traduction complète incluse.
- Lecture hors connexion des ressources installées, navigation livre/chapitre/verset,
  saisie de références françaises ou anglaises et onglets indépendants restaurés.
- Volet d’étude repliable, commentaires SWORD associés au verset et choix du
  commentaire par onglet. Les versifications doivent correspondre exactement.
- Notes de passage avec Markdown léger, étiquettes, recherche et tri ; conservation
  locale dans SQLite, sauvegarde et restauration JSON avec protection des conflits.

## Installation graphique sous GNOME

1. Utiliser un système **Linux x86_64** avec **Logiciels GNOME** et son support
   Flatpak. Selon la distribution, le greffon Flatpak de Logiciels doit être installé.
2. Si nécessaire, ouvrir [le fichier de dépôt Flathub](https://flathub.org/repo/flathub.flatpakrepo)
   dans Logiciels et ajouter cette source. Elle fournit le runtime GNOME 49.
3. Télécharger **Bible-0.1.0-alpha.1-linux-x86_64.flatpak** dans les fichiers de
   cette release. Le ZIP « Source code » n’est pas l’application installable.
4. Double-cliquer sur le fichier `.flatpak`, choisir Logiciels si demandé, puis
   **Installer**. Une connexion est nécessaire pour télécharger le runtime.
5. Ouvrir **Bible** depuis la grille des applications. Choisir et télécharger une
   Bible dans le catalogue, puis ouvrir un passage ; les textes installés restent
   lisibles hors connexion.

Ce paquet est distribué directement ici : Bible n’est pas publié sur Flathub.
Si Logiciels n’ouvre pas le paquet, vérifier son support Flatpak. En dépannage :

```sh
flatpak install --user ./Bible-0.1.0-alpha.1-linux-x86_64.flatpak
flatpak run io.github.icfmp.Bible
```

Le fichier `SHA256SUMS` permet de contrôler le téléchargement : placer les deux
fichiers dans le même dossier, puis exécuter `sha256sum -c SHA256SUMS`.
La somme vérifie l’intégrité ; elle ne constitue pas une signature de l’éditeur.

## Limites connues

- Alpha Linux x86_64 uniquement ; Windows et macOS ne sont pas validés.
- L’installation graphique sur notre poste GNOME, les dialogues de fichiers du
  portail Flatpak et un parcours complet au clavier/lecteur d’écran restent à tester.
- Pas de mise à jour automatique du paquet local. Sauvegarder les notes en JSON
  avant les essais. Ces exports contiennent les notes en clair.
- Les données Flatpak sont distinctes d’une exécution native et sont conservées
  dans `~/.var/app/io.github.icfmp.Bible/data/bible/`.
- Catalogue CrossWire initial uniquement ; aucune intégration YouVersion/Semeur
  autorisée n’est disponible. Certaines ressources sont chiffrées, indisponibles
  ou incompatibles et ne peuvent pas être installées.
- Les commentaires peuvent manquer pour un passage ; par exemple MHCC n’a pas
  d’entrée indexée en Jean 3:16. Tester Clarke sur Jean 3:16 ou MHCC sur Genèse 1:1.
  Aucun rapprochement automatique entre versifications différentes.
- Le rendu du texte SWORD ne restitue pas encore toutes les mises en page et
  annotations des éditions. Pas encore de recherche plein texte dans la Bible,
  de comparaison parallèle, de dictionnaires/Strong, de synchronisation ni d’IA.

## Signaler un problème

Créer une [issue GitHub](https://github.com/icfmp/Bible/issues/new) avec :
version `0.1.0-alpha.1`, distribution et version de GNOME, mode d’installation,
nom/version du module biblique, référence exacte, étapes de reproduction,
résultat attendu et résultat observé. Joindre une capture si utile.
Les erreurs peuvent être recueillies en lançant `flatpak run io.github.icfmp.Bible`
dans un terminal. Relire les journaux et retirer les notes personnelles,
identifiants ou autres données privées avant de les joindre.

## Vérifications et traçabilité

La publication est conditionnée à la réussite de la CI du commit étiqueté : tests
Python et GTK sous Xvfb (dont interface française), intégrations CrossWire réelles
avec réouverture hors connexion, construction Flatpak, installation du paquet et
chargement de SWORD et de l’interface dans son environnement.
Ces contrôles automatisés ne remplacent pas l’essai manuel sur notre poste GNOME.
Le commit exact, l’exécution CI et la somme SHA-256 sont ajoutés ci-dessous par
le workflow de publication. Les sources correspondantes, dépendances compilées
et instructions de construction sont jointes dans `Bible-0.1.0-alpha.1-sources.tar.gz`.
