# Installed GTK before/after gallery

Original Xvfb screenshots, without image edits. The baseline is installed bundle
41391340612 (source tree identical to published alpha 83248ef); the candidate is
installed bundle 41472220377, source 99b4689. Both use GTK 4.20.4 in the same
GNOME 49 runtime. The /app import guards, case details and unchanged-source
receipts are retained beside the images.

135 selected original screenshots are retained here; the full 337-image matrix
and all receipts are in [Actions proof 41476084834](https://github.com/icfmp/Bible/actions/runs/41476084834),
artifact source-rendering-runtime-probe. This is developer validation, not the
client's GNOME desktop acceptance.
