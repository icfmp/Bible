# Library confirmations, dedicated search and comparison selectors

Related to #165, #169 and #172. Descriptions and all current comments were read before implementation. This document records work in progress; installed packaging, captures and signed delivery remain required.

Library's persistent Installed footer originated in the shared installation completion callback and task progress state. Completion now clears success progress/status and uses an automatically dismissed native four-second AdwToast naming the captured resource's actual title. The installed row/detail remains the durable state. A per-resource error map keeps outstanding failures/retry actions when another resource succeeds; completion checks the task generation so a callback cannot overwrite a newly started task. Closing/hiding Library dismisses prior success confirmation; a hidden completion does not queue a stale toast. No timeout worker or download/persistence format changes are added.

Search has its own native header magnifier immediately before Study. It owns the existing Text/Topics widgets, models, queries, filters, results and worker lifecycle. The central passage chooser now contains only direct reference/history and book/chapter navigation. Ctrl+F opens Search; existing Ctrl+G/Ctrl+K retain passage/reference navigation and shortcut help lists the separate action. Original-text occurrence links route to Search. Ordinary reopening retains the last search mode/query/completed results; pending work is cancelled on dismissal. Search sizing uses the existing bounded owner-layout updates, without a periodic geometry timer. At the smallest supported header sizes Search and Study remain adjacent and accessible in the established adaptive menu. Unrelated popovers close on opening while required native parent menus remain available.

Both pane translation buttons now expand across their controls container. One shared GtkOverlay gives the edition label symmetric chevron clearance in a pane, centering it in the entire button, while the arrow stays at the right. The header's compact public-code treatment keeps its existing one-sided arrow clearance. The existing native states, wrapping, tooltips and independent pane chooser callbacks remain.
